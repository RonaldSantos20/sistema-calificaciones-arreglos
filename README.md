# Sistema de calificaciones con arreglos y vectores

## Descripcion
Programa introductorio en Python que utiliza una lista como vector para almacenar las calificaciones de cinco estudiantes. Permite consultar una posicion, modificar una nota y calcular estadisticas basicas.

## Objetivo
Demostrar el almacenamiento, acceso, modificacion y procesamiento de datos mediante indices, ciclos y condiciones.

## Lenguaje utilizado
Python 3.

## Funcionalidades
- Almacena cinco calificaciones iniciales.
- Consulta una calificacion por su indice (los indices comienzan en 0).
- Modifica una calificacion si el indice y el valor son validos.
- Recorre el vector con `for` y clasifica las calificaciones con `if`.
- Calcula promedio, nota maxima, nota minima y cantidad de aprobados y reprobados.
- Controla entradas numericas incorrectas y posiciones fuera del rango.

## Requisitos
Tener Python 3 instalado.

## Como ejecutar
1. Descargue o clone este repositorio.
2. Abra una terminal en la carpeta del proyecto.
3. Ejecute:

```bash
python sistema_calificaciones.py
```

En algunos equipos de Windows puede utilizar `py sistema_calificaciones.py`.
